# Third-party components

Secret Skyrim MP integrates with third-party open-source projects but is not affiliated with their maintainers or with Bethesda/ZeniMax.

## SkyMP

Pinned upstream commit used by this project:

`2abd0a0391278335face3c13ff0e2cabf76344b0`

Upstream repository: `skyrim-multiplayer/skymp`.

The vendored server runtime under `server/vendor/skymp/` remains subject to the applicable SkyMP subproject licenses and upstream terms. Source for the pinned upstream revision is available from the upstream repository. Project-specific gamemode/client changes are present in this repository.

## Mumble

Pinned client/plugin API version: `1.5.915`.

Mumble itself is not stored in Git. GitHub Actions downloads the official Windows client at build time and redistributes the runtime in generated client artifacts together with license material copied by the build scripts.

## Skyrim

No Bethesda game executable, master, BSA, or other game asset is stored in this repository or generated by CI. A legal local Skyrim installation is required.
